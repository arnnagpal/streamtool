> quit
close program.

> restore
restore previously imported data (players, seeds) after a crash.

> init
runs import, order api, match clear and scene im.

> setinfo leagueNumber weekNumber
set the league and week numbers manually, in case init or import true doesn't do it correctly.

> killfeeds
kill all previous streamlink player feed instances. they may stay running when you crash as it's an external program.

> import (true)
import player list downloaded from the leagues bot after doing /list. updates player count number on intermission. with true argument, updates league and week information as well.

> order {
	file			// get seed order from a file
	api			// get seed order from api
	show			// switch to seed order scene
	skip (seedNumber)	// remove a seed from the order and move it to the end. in case there's a need for a replay. seed number can be specified, defaults to current seed.
}
no argument: prints the seed order in terminal, doesn't change anything on obs.
with file and api arguments also sets current seed to 0. you can change this with setseed.

> mute (true|false)
set mute status on stream, works as a toggle with no argument

> update (
	auto	// enable auto-update. this is done with start command.
	stop	// disable auto-update. this is done automatically when timer ends or is stopped.
	random	// put random povs on the screen. does not check if they're playing.
)
runs update function once with no argument. switches to game scene.

> refresh (1|2|3|4)
refresh a player feed. you can select the specific feed to refresh. defaults to all.

> split
show splits from spectate_match.json, only shows people who have entered the nether. shows playerId for people who are live.

> show player (1|2|3|4)
put a selected player on screen. you can provide a playerId, their ign, or a unique character sequence in their ign. gives a syntax error if unable to find player. if no position is selected, defaults to 1.

> next
switches to the next seed scene and increments the current seed, so switching from seed 1 to seed 2 for example.

> start
start the timer for the seed and enable auto-update.

> setseed seedNumber
set the current seed number manually. seedNumber must be integer between 1 and seed count.

> scene im|ns|sl|sp|pl|lb|co|cm|iv
switch scene, im = intermission, ns = next seed, sl = seed list / seed order, sp = spectator cam, pl = players / main, lb = leaderboard, co = commentators, cm = completions, iv = interview. automatically mutes when switching to intermission and unmutes when switching to any other scene. for leaderboard and completions use the special commands (comp, lb) since they also update the data.

> interview player
select player to interview and switch to interview scene. you can provide a playerId, their ign, or a unique character sequence in their ign. gives a syntax error if unable to find player.

> timer {
game			// start the timer for the seed.
im seconds		// set and start the intermission timer. seconds must be integer.
advance|add seconds	// add seconds to the timer.
stop			// stop the timer.
}

> lb|leaderboard (seedNumber)
show the leaderboard after the current seed. attempts to download match data if missing only the current seed, effectively an auto-import. you can also provide the seed number if you want the standings after a specific seed.

> comp|completions (seedNumber)
show the completions. shows them for current seed from spectate_match.json if no argument is provided. if seedNumber is provided, shows them for the specific seed from match data.

> match {
	clear			// clear match data.
	autodl			// try to download the most recent match from the host as current seed.
	id (count)		// get a number of recent matchIds from the host. prints starting with oldest. count defaults to 1.
	host username		// set host to username. this is used to download match data.
	dl seedNumber matchId	// manually download match data for a specific seed with a specific matchId
}

> setlive player (true|false)
mark a player as live or not live. you can provide a playerId, their ign, or a unique character sequence in their ign. gives a syntax error if unable to find player. if no boolean is provided, toggles their current status.

> twitch player (twitchName)
set player's twitch if they didn't provide one or misspelt it. you can provide a playerId, their ign, or a unique character sequence in their ign. gives a syntax error if unable to find player. if no twitchName is provided, tries to get one from ranked api.

> addplayer username
add a new player. will try to get their twitch from ranked api. generally, don't use this, just re-import the player file if new people join.

> list
list all imported players and their ids.

> live
list all players who are live and their ids.

> hide player
hide a player from stream until their next split. you can provide a playerId, their ign, or a unique character sequence in their ign. gives a syntax error if unable to find player.

> unhide
unhides all hidden players.

> reload
reload obs configuration file.

> showtop (true|false)
loads timeline in reverse order if set to false

> mainspec (true|false)
replace the 4th pov on main screen with a spectator cam.

> override {
	promotions|demotions|lb1|lb2|points value		// override a specific value for leaderboard gen and display
	reset							// reset overrides
}
for promotions & demotions, set the number of them. for points, set 1st place points.

> snapshot (
	start	// store a snapshot of spectate_match.json every 10 seconds.
	stop	// stop the tool.
	load	// load stored snapshots sequentially to simulate a match.
)
testing command. don't use this.
