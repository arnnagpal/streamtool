start obs. if you want fullscreen preview projector on wayland run it in xcb mode. the side effect is that obs will sometimes just freeze when you're interacting with it. that's fine as long as you don't need to change any settings. scene switching is handled by this program. all you should have to do in obs is press go live.
run this program with java. there's a bit of delay at the start to make sure websocket is connected.
on discord, in the league-specific channel, type /list and download the file.
for the perch timer, download the private room presets zip for the week and put it in the folder you run the program from, named presets.zip. when the program starts it says if the perch timer is on.

if the program crashes, you can use this command to restore the player and seed data.
> restore

at the start, run this command. it will run import and other commands you want to run at the start. opens a file selector, just select the player file.
> init

if there's an error with setting the league information, you can do it manually with:
> setinfo leagueNumber weekNumber
leagueNumber and weekNumber are integers.

when more players reg after you run init, do /list in the discord again and import the new player file with:
> import

set yourself as the host, in order to get the match data for leaderboard.
> match host username
username is just your ign in minecraft.

set the intermission timer
> timer im seconds
seconds is an integer, the number of seconds you want your timer to be.

go live on obs.

switching from intermission at the start:
> scene co		// switch to commentator scene, do like an intro.
> lb            // when the seed is initially set to 0, this will show all the players and their previous scores.
> order show		// show the seed order.

when ready to start the seed:
> next			// increment the current seed. show the next seed type in the order. automatically switches to the dedicated seed type scene after 5 seconds.
> update		// switch to main screen when loaded in and update the top 4 people who are playing. this is initially done by the order they appear in the reg list, and later by points.
> start			// start the timer for the seed. enable auto-update.

the perch timer follows the seed number, so next and setseed switch it to the right preset. it shows up on each pov by itself during the seed, you don't need to do anything.

if the timer is out of sync
> timer add seconds		// move timer forward by a number of seconds. also accepts negative numbers if you want to go back.

useful commands during the seed:
// player is someone's ign, their id in the tool, or a unique character sequence in their ign. you can use any of these, if you do it wrong it gives a syntax error.
// position is a number from 1 to 4. 1 is the big screen, 2 3 4 are the ones on the right side, from top to bottom.

> split				// print the current splits from the spectate match file. only shows people who have entered nether. shows id for players marked as live.
> refresh (position)		// refresh a specific pov, or all of them with no argument.
> update stop			// disable auto-update
> update auto			// enable auto-update
> update			// update manually if you turned off auto-update
> show player (position)	// put a player on screen manually.
> hide player			// hide a player for their current split. they can be shown again once they get to the next split.
> unhide			// unhides all hidden players.
> timer stop			// stop the timer in case the seed is being restarted. this isn't necessary if it just ends early, you can just do comp.
> live				// list all registered players who are marked as live.
> setlive player (true|false)	// set or toggle someone's live status.

when the seed is over:
> comp				// show completions for the seed. disables auto-update if the timer hasn't ended yet.
> lb				// downloads match data, generates leaderboard and switches to leaderboard scene.
> override points (number)	// override the points in case they don't match the bot or website. enter the number of points for 1st place. then just run comp/lb again. usually this isn't necessary.
> scene mw			// show the projected multi-week relegation scores. run this after lb. kinda optional unless you want to talk about it. but show this after the last one at least.

when it's time for break:
> scene co		// switch from leaderboard to commentators. explain the break and how long it's gonna be. or you can do this on lb idk.
> scene im		// switch to intermission.
> timer im seconds	// set the intermission timer.

after break:
> scene co		// switch to commentators. welcome people back after the intermission.
> leaderboard		// show the leaderboard again. (optional)
// then just start the next seed with the previous instructions.

interview and ending stream:
> scene co		// switch to commentators.
> interview player	// switch to interview. (if you have one)
> scene co		// switch back to commentators. say goodbye. end stream on obs.

WHEN THINGS GO WRONG:

for the lb command to work, you must have the seed number set correctly and you must have downloaded all the match data.
if you skip showing the leaderboard it will break when you try to do it for a later seed. this is because it's missing a seed in the middle.
so if you want the leaderboard after seed 4 for example, the seed must be set to 4 internally and seeds 1, 2 and 3 must be imported.
the command will try to download the current seed automatically if the others are imported.

to set seed number, clear data and import a seed manually:
> setseed <seedNumber>
> match clear
> match dl <seedNumber> <matchId>

for example, to clear the data and show lb after seed 4 (assuming 4 is the latest match played on the account, if not, you can also import it manually)
> setseed 4
> match clear
> match dl 1 <id>
> match dl 2 <id>
> match dl 3 <id>
> lb

if there's an incorrect seed and you're just moving to the next seed on the list:
> order skip		// moves the current seed type to the end of the order.
> order			// see if the new order is correct.
> scene ns		// switch back to next seed scene without incrementing the seed number, which should show the correct seed type.
> setseed seedNumber	// in case the seed number is wrong, you can change that. then just reload the ns scene.
> order api		// if you mess things up and want the original order back.
// if this doesn't work, just move the seed to the end on the website and download the order again with order api. or you can just ignore it and accept that it's wrong. this is not a very user-friendly design.
